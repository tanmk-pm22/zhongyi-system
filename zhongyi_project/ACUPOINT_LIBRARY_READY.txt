【如何添加穴位图片 | HOW TO ADD IMAGES】

1. 进入Django管理后台 | Go to Admin
   http://127.0.0.1:8000/admin/

2. 登录管理员账号 | Login as Admin

3. 找到"穴位参考资料" | Find "Acupoint Reference"
   Acupuncture → 穴位参考资料

4. 选择穴位编辑 | Select Acupoint to Edit

5. 上传图片 | Upload Images
   - 2D图片：上传穴位2D示意图
   - 3D图片：上传穴位3D示意图
   - 视频链接：添加YouTube或其他视频URL

6. 保存 | Save
